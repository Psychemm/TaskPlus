To change colors or hide lists, open Google Calendar and use the task lists listed under My calendars. Hover a list and click ⋮ to pick its color.

Google Cloud setup

Google Calendar's page doesn't say which list a task belongs to, so this extension reads it from the Google Tasks API (read-only). The API requires your own free OAuth client. You only need to set this up once.

  1. Open the Google Cloud console and create a project (any name).
  2. Enable the Google Tasks API for that project.
  3. Open Google Auth Platform, click Get started, and choose External for the audience. On the Audience page, either add your Google account under Test users or click Publish app. Published apps don't make you reconnect every 7 days.
